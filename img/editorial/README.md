# Imagens de rascunhos editoriais

Esta branch recebe imagens preparadas pelo painel Campo Digital. Ela não é a
branch de publicação do GitHub Pages e não deve ser mesclada por inteiro em main
ou master. A publicação futura deve selecionar as imagens da reportagem revisada.

O repositório é público: imagens nesta branch podem ser acessadas antes de a matéria
ser publicada. Não usar esta pasta para arquivos privados ou imagens ainda sem
autorização de uso.

O backend aceita somente WebP validado, remove metadados e gera o nome pelo hash
do conteúdo. A capa tem 1200 × 675 pixels. Fotos internas preservam a proporção,
limitadas a 1600 pixels por lado e 1 MB por arquivo.

Nenhuma credencial deve ser salva nesta branch. O token de escrita fica apenas no
ambiente do backend; a conta Google autorizada é conferida em cada envio.
